# Flask Chatbot Agent

A Python-based chatbot agent built with Flask. Simple, lightweight, and easy to extend.

## Features

- Flask web application
- HTML templates for chat interface
- Static file serving
- Easy to extend with new responses

## Quick Start

```bash
# Install dependencies
pip install flask

# Run the application
python app.py

# Open in browser
http://localhost:5000
```

## Project Structure

```
agent/
├── app.py              # Flask application
├── templates/
│   ├── index.html      # Home page
│   └── chat.html       # Chat interface
└── static/
    ├── style.css       # Styles
    └── script.js       # Client-side logic
```
